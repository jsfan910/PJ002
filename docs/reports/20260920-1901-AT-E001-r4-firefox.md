## 結論（先講）

**Firefox 兩組（`firefox-1280x800`、`firefox-390x844`）在本輪環境中仍 100% 無法啟動**（68/68 測試全部於啟動階段失敗，非測試邏輯失敗）。錯誤與 AT r3 記錄的 E-B-09 完全相同：`browserType.launch: spawn UNKNOWN`。**判定為工具／執行環境限制，非產品缺陷**：同一 session、同一 Playwright 設定、同一 docker compose 服務下，Chromium 對照組正常啟動並全數通過（見下方對照測試）。

**NFR-004 退出準則第 10 項維持 4／6**（Chromium×2、Edge×2 已於前輪通過；Firefox 2 組本輪仍阻擋）。本卡按驗收要求改列 `blocked`，並在下方給出使用者可在自己機器上一次執行的指令。

## 診斷過程（已嘗試的替代方案）

1. **確認本環境非「無 Firefox 二進位檔」問題**：`npx playwright install firefox`（先前已裝，exit 0、無輸出）→ 懷疑二進位檔可能因掃毒軟體隔離而損毀，故執行 `npx playwright install --force firefox` 強制重新下載（122 MiB，完整下載記錄見下）。重新下載後**問題依舊**，排除「損毀二進位檔」假設。
2. **確認非 docker/服務未就緒問題**：`curl -u dev:dev http://localhost:8082/health` 回 `200`；同一服務上 Chromium 對照測試（`--project=chromium-1280x800 tests/e2e/us001-create.e2e.test.ts`）**4/4 全過**（13.3s），證明本機服務、環境變數、`--disable-http2 --disable-quic` 這組 launchOptions 都不是原因，問題只發生在啟動 `firefox.exe` 這個動作本身。
3. **`PLAYWRIGHT_BROWSERS_PATH`**：未設定此變數（沿用預設 `~/AppData/Local/ms-playwright`）；此變數只影響 Playwright 去哪裡找/裝瀏覽器二進位檔，不影響 Windows `CreateProcess` 層級的啟動失敗，經上述重新下載測試後判斷改這個變數不會改變結果，故未再另行嘗試（避免無意義佔用時間）。
4. **系統 Firefox `channel`**：檢查本機 `C:\Program Files\Mozilla Firefox\firefox.exe`、`C:\Program Files (x86)\Mozilla Firefox\firefox.exe`、`where firefox` 皆**查無安裝**，本機無系統版 Firefox 可用來以 `executablePath` 替代（且 Playwright 官方文件本身也不支援一般 Firefox 版本走 `channel` 參數，`channel` 僅支援 Chromium 系列如 `msedge`／`chrome`）。此路不通。
5. **底層錯誤定位**：以 Node `child_process.spawn` 直接呼叫 `firefox.exe`（繞過 Playwright），重現同樣 `Error: spawn UNKNOWN`（`errno: -4094, code: 'UNKNOWN', syscall: 'spawn'`），確認錯誤發生在 Windows `CreateProcess` 這一層，早於 Firefox 本身任何程式碼執行；Windows Defender 即時保護目前為**開啟**狀態（`DisableRealtimeMonitoring: False`），但本 session 非系統管理員，**無法查看／調整排除清單**（且調整資安設定不在本角色權責與工具授權範圍內），故無法在本輪驗證「是否為防護軟體攔截特定執行檔」這個假設，僅記錄為可能成因之一。

## 讓使用者在自己機器上執行的單一指令

若使用者要在自己（非本工具沙盒）的機器上補跑本卡範圍，於專案根目錄 Git Bash 執行：

```bash
cp .env.example .env && \
sed -i "s/^PORT=.*/PORT=8082/" .env && \
echo "POSTGRES_HOST_PORT=5434" >> .env && \
docker compose -p t0041-firefox up -d --build && \
npx playwright install firefox && \
BASE_URL=http://localhost:8082 BASIC_AUTH_USER=dev BASIC_AUTH_PASSWORD=dev \
  npm run test:e2e -- --project=firefox-1280x800 --project=firefox-390x844 ; \
docker compose -p t0041-firefox down
```

PowerShell 版本：

```powershell
Copy-Item .env.example .env
(Get-Content .env) -replace '^PORT=.*', 'PORT=8082' | Set-Content .env -Encoding utf8
Add-Content .env "POSTGRES_HOST_PORT=5434" -Encoding utf8
docker compose -p t0041-firefox up -d --build
npx playwright install firefox
$env:BASE_URL = "http://localhost:8082"; $env:BASIC_AUTH_USER = "dev"; $env:BASIC_AUTH_PASSWORD = "dev"
npm run test:e2e -- --project=firefox-1280x800 --project=firefox-390x844
docker compose -p t0041-firefox down
```
