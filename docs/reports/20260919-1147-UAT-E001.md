#### AC-001-2：空標題拒絕（無法透過前端驗證）

**做了什麼**：瀏覽器開啟 http://dev:dev@localhost:8080 試圖操作前端

**看到什麼**：前端顯示「無法連線到伺服器，請檢查網路連線後重試」紅色警告框

**根本原因**：
- 前端 HTML 成功載入（HTTP 200）
- 前端 JavaScript 資源皆成功載入
- 前端在初始化時試圖呼叫 `GET /api/v1/todos` 檢索列表
- 觀察到：前端發送的 fetch 請求未包含 Authorization 頭
- 伺服器回應 401 E_UNAUTHORIZED：`{"code":"E_UNAUTHORIZED","message":"Missing or bad formatted authorization header"}`
- 原因：`public/assets/api-client.js` 第 64～68 行的 fetch 調用缺少 `credentials: "include"` 選項，導致瀏覽器無法自動附帶 Basic Auth 凭证

**結果**：阻擋（前端無法運作）
