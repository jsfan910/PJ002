# R4 UAT 截圖說明

## 工具限制（誠實記錄）

本輪使用內建 Browser 工具（`mcp__Claude_Browser__*`）在 staging 實際操作並多次以 `computer{action:"screenshot"}` 截圖確認畫面（畫面內容見報告正文各節引用的截圖描述），但**該工具未提供「截圖存檔至本機磁碟」的參數**（不同於另一組 `claude-in-chrome` 工具的 `save_to_disk`，本次該擴充功能未連線，見交接檔 A 段）。因此本目錄無法附上實際圖檔。

## 實際採用的證據（比截圖更可驗證）

依 Leader 指示「以網路面板看到的實際請求與狀態碼」和「畫面實際文字」為證據，本輪報告正文（`docs/reports/20260919-1656-UAT-E001-r4.md`）每個操作步驟皆附：
- `read_network_requests` 取得的實際 HTTP 方法／路徑／狀態碼（已移除帳密，僅保留路徑）
- `get_page_text` 取得的畫面實際文字
- 對截圖內容的逐項文字描述（顏色、勾選、刪除線等視覺狀態，由 `computer{action:"screenshot"}` 實際檢視後如實記錄，非憑空敘述）

不含任何帳號密碼。網址列帶帳密的畫面本輪未截圖存檔（依規則本就不應存）。
