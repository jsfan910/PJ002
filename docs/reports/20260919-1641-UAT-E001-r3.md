## 操作紀錄

### 阻擋原因詳述

#### 前端瀏覽器連接問題

**症狀觀察**：
```
頁面標題：待辦事項
頁面狀態：完全載入，UI 元素呈現正常
錯誤訊息：「無法連線到伺服器，請檢查網路連線後重試」（紅色警告框）
重試按鈕：點擊無效，持續顯示相同錯誤
清單狀態：「目前沒有任何待辦事項，新增一筆開始吧」
```

**診斷步驟**：

1. **驗證 Staging 環境可用性**
   ```bash
   curl -u <username>:<password> https://todo-app-dpevsdhdva-de.a.run.app/health
   → 200 OK {"status":"ok"}
   ```
   結論：Staging 健康檢查正常

2. **驗證 API 端點可用性**
   ```bash
   curl -u <username>:<password> https://todo-app-dpevsdhdva-de.a.run.app/api/v1/todos
   → 200 OK [{"id":"...","title":"...","isCompleted":...,"createdAt":"..."}]
   ```
   結論：API 可正常返回待辦清單

3. **診斷瀏覽器 fetch 能力**
   - 嘗試在頁面 DevTools 中執行 `fetch('/api/v1/todos')`
   - 錯誤：`Failed to execute 'fetch' on 'Window': Request cannot be constructed from a URL that includes credentials: /api/v1/todos`
   - 嘗試使用 Authorization 標頭：`fetch('/api/v1/todos', {headers: {'Authorization': 'Basic ...'}})`
   - 相同錯誤

**根本原因分析**：

瀏覽器安全政策限制。Chrome/Chromium 實現的同源政策機制中，當頁面從包含認證信息的 URL 載入時（如 `https://user:pass@host/`），該頁面的 JavaScript 上下文會被標記為「不安全」，並禁止發送包含認證信息的請求。這是防止認證信息洩露的安全措施。

**驗證**：
- 頁面初始 URL：`https://<username>:<password>@todo-app-dpevsdhdva-de.a.run.app/`（帶認證）
- 通過 navigator.url 檢查：頁面認為自己在 `https://todo-app-dpevsdhdva-de.a.run.app/`（不帶認證，正確）
- 但 JavaScript 執行上下文已被標記為來自認證 URL 的上下文
