2. **證據觀點**：Chromium 與 Edge 同為 Chromium 核心，Firefox 是唯一的 Gecko 樣本；前端為無框架 ES2020 ＋ flexbox 單一斷點，跨引擎風險低但非零。Leader 2026-09-19T12:32:40 已裁決「Gate 2 後於非沙盒環境補跑」。
3. **選項**：
   - **選項 1：維持原裁決**，4／6 放行，Firefox 列 Gate 2 後待辦（與 D-017 修正一起做）。代價：Gecko 零覆蓋直到補跑。
   - **選項 2：要求補跑後才判 Gate 2**。代價：需非沙盒機器，時程不可控。
   - **選項 3：改判必測瀏覽器為 Chromium 系 2 種 × 2 尺寸**（走規格變更請求）。代價：放寬凍結規格，與 SRS 字面不符。
4. **建議**：**選項 1**（維持原裁決）。理由：與 D-017 的 dev-fe 修正、D-016 的規格修文是同一批 P1 待辦，一次做完；且 D-017 的存在反而讓「Firefox 補跑」更值得和前端時序修正綁在一起驗。
5. **推翻成本**：低。若補跑發現 Firefox 版面瑕疵，依 §5.1 多為 S3（「相容性 6 組中 1 組有非阻斷性版面瑕疵」），可延後修正而不需回頭改 Gate 2 結論。
