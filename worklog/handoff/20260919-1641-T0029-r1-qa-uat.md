### 阻擋原因（Blocked Reason）

**前端瀏覽器無法連接到 API 伺服器**

詳細說明：
```
症狀：前端頁面顯示「無法連線到伺服器，請檢查網路連線後重試」
環境驗證：
  ✓ /health 端點 200 OK（無認證）
  ✓ /api/v1/todos 200 OK（curl -u 帶認證）
  ✗ 前端 fetch 請求失敗：
    "Request cannot be constructed from a URL that includes credentials"

根本原因：
  瀏覽器安全政策限制。頁面從帶認證 URL 載入時（https://user:pass@host），
  JavaScript 執行上下文被限制，禁止發送包含認證信息的 fetch 請求。
  前端應用未實作替代認證方案（如 Authorization 標頭或 session cookie）。
```
