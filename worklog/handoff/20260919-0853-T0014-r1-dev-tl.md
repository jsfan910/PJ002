- 下一步建議（小瑕疵，不退回；給後續卡）：
  1. **給 T-0017（WI-07）—— CSS 陷阱**：`styles.css` 的 768px 斷點會把 `.add-form` 的 `flex-direction` 由 row 換成 column。T-0017 在加入逐筆待辦項目（checkbox／標題／編輯／刪除）的樣式時，**不要用 `flex: n n <px>` 的 flex-basis 寫法**，因為主軸一換方向，該 px 值就從寬度變成高度（本卡已踩過一次，輸入框變成 240px 高方塊）。改用 `min-width`／`height` 這類不隨主軸語意變化的屬性。並請在 390×844 複測逐筆項目的點擊區仍 ≥ 44×44。
